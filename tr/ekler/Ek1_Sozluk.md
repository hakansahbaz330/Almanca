## 15. Karıştırılan kelime çiftleri (Bölüm C)
*(Fark sütunu Almanca; kısa Türkçe: Symptom = belirti, Diagnose = tanı (doktor); Infektion = etken girişi, Entzündung = doku tepkisi; Schmerzen haben = hisseder, äußern = bildirir; Prophylaxe = belirli komplikasyonu önleme, Prävention = genel önleme/koruma.)*
| Çift | Fark | Örnek |
|---|---|---|
| **Symptom ↔ Diagnose** | Symptom = Beschwerde/Zeichen (Fieber, Husten); Diagnose = Name der Krankheit, **ärztlich** (Pneumonie) | „Fieber ist ein Symptom, keine Diagnose.“ |
| **Pflegeplanung ↔ Pflegedokumentation** | Planung = Ziele/Maßnahmen vorab; Dokumentation = Nachweis von Beobachtung/Durchführung | |
| **Beobachten ↔ Beurteilen** | Wahrnehmen ↔ Schlussfolgern | |
| **Infektion ↔ Entzündung** | Erreger eindringen ↔ Gewebereaktion (kann ohne Erreger) | |
| **Schmerzen haben ↔ Schmerzen äußern** | empfinden ↔ mitteilen/zeigen | |
| **Prophylaxe ↔ Prävention** | konkrete Komplikation verhindern ↔ allgemein Gesundheit erhalten/fördern | |
| **Kolonisation ↔ Infektion** | ohne ↔ mit Symptomen | |
| **Fieber ↔ Hyperthermie** | Sollwert hoch ↔ Regulation überfordert | |
| **Desinfektion ↔ Sterilisation** | keimarm ↔ keimfrei | |
| **Thrombose ↔ Embolie** | Gerinnsel am Ort ↔ verschleppt | |
| **Ventilation ↔ Perfusion** | Belüftung ↔ Durchblutung | |
| **Mobilität ↔ Mobilisation** | Fähigkeit ↔ Maßnahme | |
| **Ressource ↔ Problem** | Fähigkeit ↔ Beeinträchtigung | |
| **Sturz ↔ Absturz** | Boden/tiefere Ebene ↔ aus erhöhter Position | |
| **BLS ↔ ALS** | Basis ↔ erweitert | |
| **Lysis ↔ Krisis** | langsam ↔ abrupt (Notfall) | |
| **Hautarten Leisten- ↔ Felderhaut** | Hände/Füße ↔ Rest | |
| **Mitose ↔ Meiose** | 2 gleiche ↔ 4 verschiedene | |
| **Arterie ↔ Vene** | weg vom ↔ zum Herzen | |

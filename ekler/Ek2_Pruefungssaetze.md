# Ek 2 — Sınavda kullanılabilecek Almanca cümle kalıpları

> [← Ana rehber](../README.md) · Kullanım: Kalıbı seçin → boşluğu konuyla doldurun. **Kural:** Operatör ile kalıbı eşleştirin ([10](../10_Dokumentation_und_Operatoren.md)).

## 1. Tanımlama (DEFINIEREN / BESCHREIBEN)
- **X ist …** / **Unter X versteht man …** — *Unter Prophylaxe versteht man Maßnahmen, die Komplikationen vorbeugen.*
- **X bezeichnet …** — *Mobilität bezeichnet die Fähigkeit, sich selbstständig zu bewegen.*
- **Charakteristisch für X ist …** — *Charakteristisch für Fieber ist die Sollwerterhöhung im Hypothalamus.*
- **X besteht aus …** — *Die Haut besteht aus Ober-, Leder- und Unterhaut.*
- **Es zeigt sich …/Auffällig ist …** — *Auffällig ist eine nicht wegdrückbare Rötung am Kreuzbein.*

## 2. Erklären / Begründen
- **… weil … / da …** — *Er hat Angst, weil er bisher allein gelebt hat.*
- **Das liegt daran, dass …** — *Das liegt daran, dass die Muskel-Venen-Pumpe bei Immobilität nicht aktiviert wird.*
- **Aus diesem Grund / Deshalb / Daher …** — *Aus diesem Grund ist Frühmobilisation wichtig.*
- **Dies führt dazu, dass …** — *Dies führt dazu, dass das Blut langsamer fließt.*
- **… sodass …** — *… sodass er auf Hilfe angewiesen ist.*
- **Dafür spricht, dass … / Ein Argument dafür ist …**

## 3. Vergleichen
- **Im Gegensatz zu … / Während …, …** — *Während Fieber auf einer Sollwerterhöhung beruht, ist Hyperthermie ein Versagen der Wärmeabgabe.*
- **Beide … / Gemeinsam ist …** — *Gemeinsam ist beiden, dass die Temperatur erhöht ist.*
- **Der Unterschied besteht darin, dass …**
- **Ähnlich wie … / Anders als …**

## 4. Beschreiben von Zeichen/Beobachtungen
- **Ein wichtiges Anzeichen dafür ist …** — *Ein wichtiges Anzeichen für eine Exsikkose ist eine stehende Hautfalte.*
- **Typische Symptome sind …** — *Typische Symptome einer Lungenembolie sind plötzliche Atemnot und Brustschmerz.*
- **… weist auf … hin** — *Ein verminderter Turgor weist auf Flüssigkeitsmangel hin.*
- **… spricht für …** — *Rötung, Schwellung und Überwärmung sprechen für eine Entzündung.*

## 5. Maßnahmen
- **Die Pflegemaßnahme dient dazu, … (zu …)** — *Die Frühmobilisation dient dazu, einer Thrombose vorzubeugen.*
- **Um … zu …, wird/werden …** — *Um Stürze zu vermeiden, werden Stolperfallen entfernt.*
- **Zunächst ist zu beachten, dass …** — *Zunächst ist zu beachten, dass der Patient informiert und einverstanden sein muss.*
- **Zuerst … anschließend … zuletzt …**
- **Dabei ist darauf zu achten, dass …** — *Dabei ist darauf zu achten, dass die Intimsphäre gewahrt bleibt.*
- **Mithilfe von … kann … erreicht werden**

## 6. Evaluation / Kontrolle
- **Anschließend wird überprüft, ob …** — *Anschließend wird überprüft, ob das Ziel erreicht wurde.*
- **Die Maßnahme ist wirksam, wenn …** 
- **Falls das Ziel nicht erreicht wird, wird die Planung angepasst.**

## 7. Eskalation / Sicherheit
- **Bei einer Verschlechterung des Zustands muss …** — *… muss die Pflegefachkraft bzw. der Arzt umgehend informiert werden.*
- **Bei … ist sofort der Notruf 112 abzusetzen.**
- **Die Maßnahme darf nur nach ärztlicher Anordnung / nach Rücksprache mit der PFK erfolgen.**
- **Dies liegt nicht im Verantwortungsbereich der Auszubildenden.**

## 8. Folgern / Zusammenfassen / Urteilen (AFB III)
- **Daraus ergibt sich …** / **Folglich …**
- **Zusammenfassend lässt sich sagen, dass …**
- **Meiner Einschätzung nach … , weil …** / **Ich komme zu dem Schluss, dass …**
- **Einerseits …, andererseits …** (Pro/Contra) · **Abschließend …**
- **Aus Sicht des Patienten könnte … bedeuten, dass …** (DEUTEN)

## 9. Hastayla iletişim kalıpları
| Amaç | Cümle |
|---|---|
| Tanışma | Guten Tag, ich bin … und für Sie zuständig. |
| İzin | Darf ich hereinkommen? / Ist es in Ordnung, wenn …? |
| Açıklama | Ich werde jetzt … Das dauert etwa … |
| Seçenek | Möchten Sie das lieber selbst machen? |
| Anlama kontrolü | Haben Sie das verstanden? Möchten Sie noch etwas fragen? |
| Empati | Das verstehe ich. / Das muss unangenehm sein. |
| Ağrı | Wo genau haben Sie Schmerzen? Wie stark auf einer Skala von 0 bis 10? |
| Sınır | Das darf ich nicht entscheiden; ich frage die zuständige Pflegefachkraft. |
| Hata/Risk | Mir ist aufgefallen, dass … Ich möchte das melden. |
| Acil | Hilfe! Der Patient reagiert nicht und atmet nicht normal! |

## 10. Doktor / Ekip (SBAR)
**S:** *Ich rufe an wegen Herrn …, Zimmer … Seine Temperatur ist auf … gestiegen.* · **B:** *Er ist … Jahre alt, Z. n. …* · **A:** *Ich schätze die Situation so ein, dass …* · **R:** *Ich bitte um … / Soll ich …?*
